A make.fun "The Funniest Toaster Error Message" entry: a tiny Python 3.13 program (stdlib only) that writes one original one-line error message a kitchen toaster would show its owner to `/output/entry.txt`.

The line it writes (74 characters, one line):

> Error: lever stuck. Your toast has chosen to stay. I support its decision.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
